# Contributing

The core of this repository is frozen, so most contributions are evidence, not text. Useful
contribution types:

- **Usage evidence** (issue template): a real situation in which the text gave no answer,
  gave a wrong answer, or was systematically misread. This is the only thing that reopens
  the core.
- **Translation divergence** (issue template): a semantic difference between the English
  canon and the Turkish source.
- **Wording defect:** a reading that contradicts the doctrine's evident intent.
- **Worked example:** a real case from a field the examples do not yet cover, especially one
  where the boundary is implicit and social.
- **Implementation report:** what happened when you gave ESSENCE.md to an agent or a team.

Open an issue first. Pull requests that change DISCIPLINE.md or ESSENCE.md without a linked
evidence issue will be closed with a pointer to [GOVERNANCE.md](GOVERNANCE.md).
